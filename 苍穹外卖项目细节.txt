问题1：录入的用户名已存在，抛出异常后没有处理，没处理的话，控制台会抛出错误。
用全局的异常处理器sky-server/handler/GlobalExceptionHandler，创建exceptionHandler方法，在方法里添加如下代码：
@ExceptionHandler
    public Result exceptionHandler(SQLIntegrityConstraintViolationException ex) {
        String message = ex.getMessage();
        if(message.contains("Duplicate entry")){
            String[] split = message.split(" ");
            String username = split[2];
            String msg = username + MessageConstant.ALREADY_EXISTS;
            return Result.error(msg);
        }else{
            return Result.error(MessageConstant.UNKNOWN_ERROR);
        }
}
目的是向前端输出：xxx已经存在的提示。核心思想是：提取错误那段话的第3个词，然后拼接后输出。

问题2：新增员工时，怎么将创建人id和修改人id设置为当前员工？
JWT认证机制：用户发起请求发送用户名和密码，后端进行校验，如果验证通过就生成JWT Token，将Token返回给客户端，客户端会保存Token，在后续请求的请求头中都会携带JWT Token，请求会被拦截器拦截到，会检查Token，如果通过就会展示数据，如果没有通过就会返回错误信息。

问题是：在解析出登录员工id后如何传递给Service的save方法？答：通过ThreadLocal工具类，它可以操纵thread线程里的threadlocalmaps变量，为每个线程提供单独一份的存储空间，具有线程隔离的效果，只有在线程内才能获取到对应的值，在线程外则不能访问。每当请求到来时，容器会产生一个新的线程处理请求，将拦截器里解析到的用户id存到线程里，等真正用到时，再通过threadlocal的get方法获取。

VO是视图对象，用于前端数据的展示，所以一般是controller层把VO传给前端，然后前端展示。
DTO是传输对象，用于接受前端传来的请求参数。

微信支付流程：
1.用户在小程序下单
2.小程序请求商户后台系统
3.商户系统检查参数，返回vo对象，包含订单号属性
4.小程序请求商户系统，申请微信支付
5.商户系统包装用户的openid，金额，订单号成json格式，调用微信下单官方接口JSAPI
6.微信官方返回预支付交易会话标识给商户系统
7.商户系统将加密后的数据以及支付参数返回给小程序
8.小程序提醒用户支付，用户确认支付
9.小程序调用微信支付官方接口 wx.requestpayment
10.微信官方返回支付结果给小程序
11.小程序显示支付结果
12.微信官方推送支付结果给商户系统，通过回调函数，参数在下单时已设置好
13.商户系统更新数据库

 (来单提醒)分析设计 
用户下单并且支付成功后，需要第一时间通知外卖商家，通知的形式有如下2种：语音播报，弹出提示框。
通过WebSocket实现管理端页面和服务端保持长连接状态。
当客户支付后，调用WebSocket的相关API实现服务端向客户端推送消息。
客户端浏览器解析服务端推送的消息，判断是来单提醒还是客户催单，进行相应的消息提示和语音播报。
约定服务期发送给客户端浏览器的数据格式位JSON，字段包括：type（消息类型，1来单提醒，2客户催单），orderId，content。

微信支付流程：
1. 准备阶段（账号与配置）

· 申请商户号：在微信支付商户平台申请，这是收款主体。
· 绑定应用：在商户平台将你的小程序、公众号或APP的AppID与商户号关联。
· 获取密钥：在商户平台【API安全】中设置并保存好：
  · API密钥 / APIv3密钥：用于签名和解密，绝密！
  · 商户号(MCHID)：你的身份ID。
  · API证书：部分接口（如退款）所需。

2. 后端集成（核心与安全）

· 统一下单：接收前端请求，调用微信API生成预支付订单(prepay_id)。（微信后台调用商户系统：当前商户系统的ip是笔记本的ip，仅仅只是局域网内的ip地址，要求获得公网ip，可以使用内网穿透技术解决。）
· 二次签名：使用私钥对prepay_id等参数再次签名，生成前端所需的支付参数包。
· 处理回调：
  · 最重要的一步：支付成功后，微信会POST通知你的后端。
  · 必须验证签名并解密数据，确保通知真实可靠。
  · 根据通知结果更新订单状态（如“已支付”），并返回成功响应给微信。

3. 前端调用（唤起支付）

· 收到后端返回的参数包后，调用微信SDK（如 wx.requestPayment）唤起支付界面。
· 注意：前端成功回调仅代表支付流程完成，不能作为支付成功的确凿证据，最终状态需依赖后端回调。
